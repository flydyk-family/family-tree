Portrait-oval frame styles

Each card shows the same frame on a photo (left, sepia bust) and the initials placeholder (right) — drawn in the real faded XIX-c. palette on parchment. Click the one that feels right; we can also blend ideas.

A · Engraved double-rule

Two fine concentric lines — an ink outer rule + a thinner bark inner rule. Minimal, modern, quietly antique (like a steel-engraving border). Uses only existing palette tokens.

B · Faded gilt bevel

A thick beveled band with a soft gold-to-bronze gradient + a top sheen line — the daguerreotype / cameo look. Richest & most "period". Needs one new muted-gilt token (kept desaturated to fit the palette).

C · Matted album oval

A solid bark "mat" ring around the photo with a soft inner vignette — like an oval cut-out in a Victorian carte-de-visite album. Warm and tactile; existing tokens only.

D · Beaded gilt edge

A fine ink ring with a "beaded/pearled" gold dotted inner band — the ornamental locket look. Delicate; reads well even at small node sizes. Needs the same muted-gilt accent as B.

Note: at real node size the medallion is only ~24–38 px wide, so finer details (B's sheen, D's beads) soften — the photo + frame silhouette is what reads from a distance.
